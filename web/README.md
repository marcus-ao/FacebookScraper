# 审校台

给业务同事用的德语审校界面。设计见 [DESIGN.md](DESIGN.md)，
需求背景见 [docs/REQUIREMENTS.md](../docs/REQUIREMENTS.md)。**本文件只讲怎么跑。**

## 当前可用功能

审校页保留英文与德语对照，把正文、话题标签、链接分开编辑。Facebook 的链接区展示
只读映射，并允许为本篇填写德语落地页、打开检查和确认。Instagram 会移除原文 URL，
用预设或自定义话术引导至 bio；bio 地址只读，未设置时显示“未配置”。

品牌与型号标签保持原样；语义标签可手工选择，也可请求模型生成德语候选。候选必须由人
采用、确认和保存；没有实际采样数据时明确标注“未采样”，不声称掌握热榜。标签推荐失败
不影响手工编辑。Instagram 的字符数与标签数接近上限时提示，保存不会自动截断。

点“保存”会追加完整文案到账号目录的 `translated_human.jsonl`，分区选择追加到
`localization.jsonl` 并绑定源文和人工稿版本。人工稿优先于后续机器翻译；旧页面不能覆盖
新版本。源帖更新后保留人工草稿，载入新原文及链接后重新复核。操作人员暂记为空。

“单篇优化”只追加本篇指令，不改模板；模板以原始文本只读展示。文案候选采用后进入
未保存的正文编辑区。图片优化异步处理，显示费用估算依据与剩余次数，每张默认最多
3 次；已受理的失败请求也计入次数，避免重复扣费。人工放置的图片继续优先。
优化任务与付费记录留在 `state/`；重启留下的未闭合任务不会自动重放。

第三方作者的原帖先进入待处理列表。详情中的“翻译这篇”需要运营确认本篇可处理，
随后才生成文案与图片。许可只绑定这一篇的原文、作者关系和原图，不改全局作者名单；
这些依据变化后要重新确认。过程有异步进度，已完成的产物仍进入同一个审校页。

可保存产品分类，并按月份、分类以及“待处理 / 已挂起 / 已处理”筛选。挂起默认在
3 个工作日后恢复（上海时间周一至周五，默认天数取 `review.snooze_default_days`）。
到期恢复由 scheduler 调用 `core.review.wake_due`；只启动 Web 不会自动唤醒。
“不发”必须填写理由；人工接管后可回填发布链接。这两种决定不会被源帖更新撤销。

“下载并由我处理”先准备 ZIP，成功后记录人工接管，包含当前有效德语文案、图片、
源帖元信息与说明。缺德语图时明确标注使用原图；本地素材不完整时不转移状态。已接管
的帖子可重新下载。`review_items.jsonl` 保存审校记录，页面显示上海时间。

“通过并创建排期”使用运营填写的柏林时刻，调用真实审批入口；本机发布核验未完成或
内容不满足条件时，按钮禁用并说明原因。冲突时由人选择其他时刻，系统不会自动顺延。
只有回读确认成功才显示已排期。“发布月历”展示最近成功读取的 Business Suite 缓存，
包含在后台手工创建的帖子；刷新失败保留旧数据并标出提示，缓存不替代提交时的核验。

可用 `/?task=fa_neakasaofficial%2F帖子ID` 直达详情，或 `/?view=calendar` 打开月历。
刷新保留当前页面，离开详情会保护未保存的草稿。列表按需更新 SQLite 展示索引；索引
不可用时回到源文件读取，不改变保存与发布判据。旧的 `fake_writer.py` 和
`web/_fake_state.json` 只作为原型历史保留，当前应用不读写它们。

## 跑起来

在 Git worktree 中启动时，默认读取该 worktree 自己的 `archive/` 与 `state/`。
它们与原工作区的真实归档互相独立；新 worktree 尚未准备数据时，列表为空是正常情况。
不要为演示直接修改原工作区的归档。离线验证使用 `tests/tests_web_review.py` 自动创建的
临时源帖和译文，测试结束后清理。

### 生产机（不装 Node）

```
.venv\Scripts\python.exe -m uvicorn web.api.app:app --port 8765
```

打开 http://127.0.0.1:8765/ 。前端是静态文件，由 FastAPI 直接伺服，
**不需要 Node 运行时、不需要 npm install、断网也能跑**。

### 开发机（改前端时）

```
cd web\ui
npm install
npm run dev            # 5173，/api 自动转发到 8765
```

后端仍然要另起一个 uvicorn。改完之后：

```
npm run build          # 产出 web/ui/dist/
```

**把 `web/ui/dist/` 拷到生产机**即可。`dist/` 与 `node_modules/` 都在
`.gitignore` 里——构建链只存在于开发环境，这是同时满足「用 Vue」和
「不破坏极简依赖」的唯一方式。

### 不开界面，只看数据

```
.venv\Scripts\python.exe -m web.api.reader --list
.venv\Scripts\python.exe -m web.api.reader --detail in_neakasa.tech/3973012230169803390
```

零网络、零费用；读取列表可能重建可删除的 SQLite 展示索引。

## 风险预扫描是静态文件

`web/api/fixtures/risks.json` 是**预跑存下来的**，原型阶段不实时调 LLM
（零成本、零延迟、演示当场不会因为 API 抖动而尴尬）。

`kind` 只允许三种：`pun` / `ambiguous` / `us_only`。
金额、单位、标签由 `core/translated.py` 的 regex 负责，**不进这个文件**。

⚠️ 当前文件里的内容是**按设计文档三类风险手写的示例**，锚点落在真实原文的
真实位置上，但判断不是 LLM 出的。要换成真数据，需要对那几篇原文跑一次
预扫描——**那一步花钱**。
