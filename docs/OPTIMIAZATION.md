## 6. 实施顺序

1. **数据安全：** 备份/核验 archive/state；审校账本损坏失败闭合；合并恢复改动。
2. **付费安全：** 孤儿模型任务恢复；统一快照投影；不确定计费/提交场景。
3. **可用界面：** 90 天历史；跨月适配；真实风险源与 sampler 的降级显示。
4. **企业集成：** 飞书当前内容、去重、日报；云盘版本与补送；企业权限实测。
5. **发布与运行：** 新单渠道 probe → 代码与证据 → 用户确认后的 FB-only/IG-only 验收 → 当前 scheduler 安装。

每一项完成后先更新“代码未完成”为“离线通过”；只有拿到外部证据才更新为“真实通过”。
