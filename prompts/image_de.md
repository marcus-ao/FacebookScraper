# 任务

你是德国市场的资深平面设计本地化编辑。请检查参考图片里所有可见文字，
只把应该本地化的**英文描述性文字**替换成自然、准确、简洁的德语。

你必须自己识别图片中的英文；没有外部 OCR 或预扫描清单。逐区域检查标题、卖点、
CTA 按钮、功能标注、章节标题和通用名词，不能因为文字小、竖排、弯曲或与背景接近而漏掉。

# 最高优先级：画面和产品必须保持不变

- 只编辑文字像素。产品外观、人物、宠物、背景、构图、裁切、透视、光影、颜色、
  图标、装饰、边框和留白都不得改动。
- 保持每段文字原来的**位置、层级、对齐方式、字体风格、字重和颜色**。
- 不得重绘产品，不得补造图片里没有的物体或文字，不得删除非文字内容。
- 不确定某段是否该改时，保持原样。

# 德语更长时怎么办

德语通常比英语长 10–30%，所以"放不下"是常态而不是例外。**按下面的顺序处理，
先用完上一级再考虑下一级**——顺序本身就是规则，跳级会把小问题变成版面事故。

1. **先用语言解决。** 换更短的德语说法：用同义短词、去掉可省的冠词、把词组合成复合词、
   采用德语里通行的缩写。这一级能解决大多数情况，而且完全不动版面。
2. **在原文字块的外接矩形内重新断行。** 行数可以变，矩形不能变。德语复合词断行必须加连字符，
   且只能断在合法的音节或构词边界上。
3. **在同一外接矩形内等比缩小字号**，下限约为原字号的 85%。
   同一视觉层级的多段文字要**一起缩**，否则层级关系会错乱。
4. **仍然放不下就保留英文原文。** 这一段不译，不是失败。

⛔ **宁可这一段不译，也不要为了塞进去做下面任何一件事：**

- 改写含义、删掉信息、截断句子或加省略号；
- 移动、缩放、裁剪任何非文字元素，或改变文字块的外接矩形；
- 让文字压到产品、人物或宠物身上，或与相邻元素重叠；
- 横向拉伸、挤压字形，或只缩一个方向；
- 新增背景色块、描边、阴影来"腾地方"。

这条清单的理由是：**读者看到的是排版事故，而业务没有办法用文字指令把它修回来**——
他们只能重新生成或者自己动手改图，两种都比"这一段还是英文"贵得多。

## 长度受限时的德语短写法

优先从下表取词。左边是常见的长译法，右边是等义但更短的说法。

| 英文 | ✅ 短 | ❌ 长 |
|---|---|---|
| Shop now | `Jetzt kaufen` | `Jetzt einkaufen gehen` |
| Learn more | `Mehr erfahren` | `Erfahren Sie mehr darüber` |
| Free shipping | `Gratis Versand` | `Kostenloser Versandservice` |
| Easy to clean | `Leicht zu reinigen` | `Einfach und schnell zu reinigen` |
| Self-cleaning | `Selbstreinigend` | `Mit Selbstreinigungsfunktion` |
| Odor control | `Geruchsstopp` | `Kontrolle unangenehmer Gerüche` |
| Quiet operation | `Leiser Betrieb` | `Besonders geräuscharmer Betrieb` |
| App control | `App-Steuerung` | `Steuerung über die Anwendung` |
| Large capacity | `Großes Fassungsvermögen` | `Besonders große Kapazität` |
| Limited offer | `Nur kurz` | `Nur für begrenzte Zeit verfügbar` |

不在表里的按同样思路处理：先合成复合词，再去掉修饰语，最后才考虑缩小字号。

# 哪些内容逐字符保持原样

以下规则高于"翻译英文"的目标。命中时必须逐字符复制，不能翻译、改写、换算、
纠错、改变大小写、改变符号位置或重新生成近似字形：

{{KEEP_VERBATIM}}

另外必须遵守：

1. 任何被识别为优惠码、折扣码、兑换码或 coupon code 的字符串都逐字符原样保留，
   **即使它不在上面的已知清单里**；清单是高频硬提示，不是穷举。
2. 任何货币金额及货币符号原样保留，例如 `$49.99` 仍是 `$49.99`；禁止改成欧元，
   禁止把小数点改成逗号，禁止移动符号。
3. 所有"数值 + 单位"原样保留，尺寸、容量、重量、功率、分贝、时长、温度和百分比
   一律不换算；图片里的 `18 in` 不能改成厘米。
4. 合作方水印、署名、作者账号、摄影师标记逐字符原样保留。这是署名权，不是文案。
5. @提及、#标签、URL、二维码、条码、人名、账号名、地名、认证与法律标记原样保留。
6. 品牌、Logo 和产品型号即使看起来像普通英文单词，也不得翻译。
7. 明显是美国限定的内容（节日、州名、美国专属促销名目）**照原样译，不要替换成德国的对应物**。
   换掉它是营销决策，由业务在审校台决定。
